# SYNTAX — bond-ops manuscript tokens

Prose sections (numbered `[0-9]*.md`) may reference tokens from the map
generated by `src/bond_ops/manuscript_variables.py` via
`scripts/z_generate_manuscript_variables.py` into
`output/variables/manuscript_variables.json`.

| Token | Source |
|---|---|
| `{{SUITE_NAME}}` | inventory constant (`PROJECT BOND`) |
| `{{PACKAGE_NAME}}` | manuscript `config.yaml` → `package.name` |
| `{{CODENAME}}` | manuscript `config.yaml` → `package.codename` |
| `{{SUITE_SIZE}}` | inventory constant (33) |
| `{{FILM_COUNT}}` | inventory constant (27) |
| `{{INFRA_COUNT}}` | inventory constant (6) |

Tokens are used with surrounding `{{` / `}}`. The cross-reference test
(`tests/test_manuscript_variables.py`) scans only numbered prose sections
(`[0-9]*.md`) so reference/guide docs that legitimately illustrate the syntax
do not false-positive.
